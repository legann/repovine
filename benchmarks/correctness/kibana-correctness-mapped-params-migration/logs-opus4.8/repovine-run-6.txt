## Summary

Added **saved-object model version 14** for the alerting `alert` (rule) type that lowercases each rule's `params.severity`. The crux: `severity` isn't a standalone value — it's coupled to two other stored surfaces, both of which version 14 handles.

### Changed behavior
- On upgrade, every rule whose `params.severity` is a non-lowercase string (e.g. `High`, `MEDIUM`, `Critical`) is rewritten to canonical lowercase.
- The sortable projection `mapped_params.severity` (what find/sort/filter actually reads, via `SEVERITY_MAP`) is recomputed from the normalized value using the same helper the write path uses (`getModifiedValue`), so a miscased rule that previously projected to `''` now sorts/filters correctly.
- Rules already lowercase, or with no `severity` param, return unchanged.
- Because `params` and `mapped_params` are in the rule's **decryption AAD**, the version runs inside `encryptedSavedObjects.createModelVersion` (decrypt → transform → re-encrypt), so `apiKey`/`uiamApiKey` stay decryptable. Without this, changing an AAD value would make every API-keyed rule unrunnable.
