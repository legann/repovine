## Summary

Added saved-object model version **14** to the alerting **rule** (`alert`) type that normalizes each existing rule's `params.severity` string to lowercase, and recomputes the coupled `mapped_params.severity` projection so the stored document stays self-consistent.

### Changed behavior
- On upgrade, any rule whose `params.severity` is a string with uppercase letters (`High`, `MEDIUM`, `Critical`, …) is rewritten to its lowercase form (`high`, `medium`, `critical`).
- For those same rules, `mapped_params.severity` is recomputed via `getMappedParams` (e.g. `[expr]`), restoring the invariant `[expr]` that find/sort/filter depends on.
- Rules with already-lowercase severity, no `severity` param, or a non-string `severity` (e.g. numeric ML thresholds) are returned untouched — no rewrite, no crash.
