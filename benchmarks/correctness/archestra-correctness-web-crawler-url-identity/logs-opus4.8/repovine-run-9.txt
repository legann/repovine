**Design decision — canonicalization is identity-only, not applied to fetched URLs.** `normalizeCrawlUrl` feeds the crawl **seed** (`:132`, `:173`), scope derivation (`:194`, `:355`), and discovered links (`:586`). Host-lowercasing is safe everywhere (case-insensitive), so it sits in the base `normalizeCrawlUrl`.

**Migration correctness.** It re-derives `source_url` with the *same* transforms and recomputes `[expr]` (core `sha256()`, so it works under PGlite where the test suite applies migrations — `pgcrypto`'s `digest()` is unavailable there).
