## Summary of changed behavior

A monitor may now target at most 100 locations (constant `[expr]`). The check lives in `getMonitorLocations` — the single function where every create/update write resolves its final location set — and fires after invalid-location resolution and deduplication, so it counts the unique set that would actually be persisted. Exceeding it throws `InvalidLocationError` with a clear message ("A monitor cannot target more than 100 locations, but N were specified (Elastic managed and private locations combined). Remove some locations and try again."). Exactly 100 is still allowed.
