## Summary

Synthetics monitors are now limited to **100 locations per monitor** on create and update. The rule lives in `validateMonitor` behind an explicit `enforceMaxLocations` opt-in, and the check runs against the normalized, deduplicated location set (public + private merged — `getMonitorLocations` returns `uniqBy(…)`). Exceeding it returns the standard validation failure shape: reason "Monitor has too many locations" plus details naming the configured count and the 100 limit — an HTTP 400 on the CRUD routes, and a per-monitor `failedMonitors` entry on project push.
